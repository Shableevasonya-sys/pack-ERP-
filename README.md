# pack-ERP
Анализ рынка ERP-систем в Российской Федерации

Учебный проект по курсу «Анализ рынка ИС и ИКТ» (2 курс, Бизнес-информатика).

Автор: Шаблеева София Григорьевна.

В репозитории собраны материалы практик 1–11: от построения базы знаний (Pack) до продвинутых аналитических фреймворков (PEST, SWOT, 5 сил Портера, Magic Quadrant, Hype Cycle) и сборки итогового текста (MVP)
