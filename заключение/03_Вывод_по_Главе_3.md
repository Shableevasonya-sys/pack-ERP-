# Выводы по Главе 3 (Тренды и рекомендации)

Основные технологии рынка ERP: low-code находится в фазе технологического триггера (показатели: рост публикаций, мало внедрений), встроенный ИИ — в фазе пика завышенных ожиданий (расходы 4,5 млрд руб., мало запусков). 

Для вендора это означает необходимость запускать пилоты ИИ и low-code без обещаний массового результата; рекомендация — инвестировать в миграцию на отечественные СУБД, где рынок уже на плато. Оценка опирается на данные TAdviser, iKS-Consulting, Минцифры, 2024.

На основе анализа среды (Портер, PEST) рекомендована стратегия MVP для нишевых вендоров: запуск облачного SaaS-решения с ИИ-модулем для строительного или логистического бизнеса. Это позволит обойти барьеры входа и занять свободную нишу.
